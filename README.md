# برد برنامه‌ریزی مطالعه | Study Sprint Board

یک پروژهٔ آموزشی برای مدیریت کارهای مطالعاتی با JavaScript ساده،
Vite و Tailwind CSS.

کارها در سه ستون «برای انجام»، «در حال انجام» و «انجام‌شده»
نمایش داده می‌شوند.

## امکانات

- نمایش شش کار نمونه در اولین اجرا
- افزودن کار با عنوان، موضوع و اولویت
- جلوگیری از ثبت عنوان یا موضوع خالی و فقط شامل فاصله
- ویرایش عنوان، موضوع و اولویت با امکان لغو
- تغییر وضعیت و جابه‌جایی کارت‌ها بین سه ستون
- حذف کار پس از تأیید
- جستجو در عنوان و موضوع بدون حساسیت به حروف بزرگ و کوچک انگلیسی
- فیلتر اولویت به‌صورت هم‌زمان با جستجو
- پاک کردن فیلترها
- نمایش پیام متفاوت برای ستون خالی و نبود نتیجهٔ جستجو
- نمایش تعداد کل کارها و تعداد هر وضعیت
- محاسبهٔ درصد پیشرفت از تمام کارها، مستقل از فیلترها
- ذخیرهٔ تغییرات با localStorage
- حفظ برد خالی پس از بازخوانی صفحه
- بازنشانی کارهای نمونه پس از تأیید
- چیدمان واکنش‌گرا و کنترل‌های قابل استفاده با کیبورد
- نمایش متن کاربر با textContent

## ابزارهای استفاده‌شده

- HTML
- JavaScript
- Tailwind CSS
- Vite
- Git و GitHub

## نصب و اجرا

برای اجرای پروژه به Node.js و npm سازگار با نسخهٔ Vite پروژه نیاز است.

پس از دریافت پروژه، در پوشهٔ اصلی اجرا کنید:

```bash
npm install
```

برای اجرای محیط توسعه:

```bash
npm run dev
```

برای اجرا داخل GitHub Codespaces:

```bash
npm run dev -- --host 0.0.0.0
```

سپس پورت اعلام‌شده در ترمینال را از بخش Ports در مرورگر باز کنید.

## ساخت نسخهٔ نهایی

```bash
npm run build
```

خروجی نهایی در پوشهٔ dist ساخته می‌شود.

برای پیش‌نمایش محلی خروجی ساخته‌شده:

```bash
npm run preview
```

برای پیش‌نمایش داخل Codespaces:

```bash
npm run preview -- --host 0.0.0.0
```

## فایل‌های اصلی

- index.html: صفحهٔ ورودی برنامه
- src/main.js: داده‌ها، ساخت کارت‌ها، رویدادها، فیلترها و ذخیره‌سازی
- src/style.css: وارد کردن Tailwind و تنظیم فونت
- vite.config.js: تنظیم پلاگین Tailwind برای Vite
- package.json: بسته‌ها و دستورهای پروژه
- package-lock.json: نسخه‌های ثبت‌شدهٔ وابستگی‌ها
- .gitignore: فایل‌ها و پوشه‌هایی که نباید وارد Git شوند

## ساختار داده‌ها

هر کار این ویژگی‌ها را دارد:

- id: شناسهٔ یکتا و ثابت
- title: عنوان
- subject: موضوع
- priority: یکی از low، medium یا high
- status: یکی از todo، doing یا done

آرایهٔ tasks وضعیت فعلی برنامه را نگهداری می‌کند.
تابع createTaskCard هر کارت را می‌سازد.
تابع renderBoard کارت‌ها را براساس وضعیت و فیلترها نمایش می‌دهد.
تابع updateDashboard آمار را از کل آرایهٔ tasks محاسبه می‌کند.

## ذخیره‌سازی

داده‌ها با کلید زیر در localStorage ذخیره می‌شوند:

study-sprint-board-tasks-v1

پس از افزودن، ویرایش، حذف یا تغییر وضعیت، داده‌ها ذخیره می‌شوند.
در باز شدن مجدد صفحه، اطلاعات با loadTasks بازیابی می‌شوند.

اگر اطلاعات ذخیره‌شده خراب یا نامعتبر باشند، برنامه به کارهای نمونه
برمی‌گردد. اگر ذخیره‌سازی انجام نشود، پیام خطا نمایش داده می‌شود.

## محدودیت‌ها

- برنامه بک‌اند، حساب کاربری یا همگام‌سازی بین دستگاه‌ها ندارد.
- اطلاعات به مرورگر و آدرس سایت وابسته‌اند.
- پاک کردن داده‌های سایت می‌تواند اطلاعات کارها را حذف کند.
- جستجو و انتخاب فیلتر پس از Refresh به حالت اولیه برمی‌گردند.
- عنوان و موضوع از نظر خالی نبودن بررسی می‌شوند؛ معنی متن بررسی نمی‌شود.
- بازنشانی، کارهای فعلی را با شش کار نمونه جایگزین می‌کند.

## روش بررسی دستی

1. یک کار اضافه کنید.
2. عنوان، موضوع و اولویت آن را ویرایش کنید.
3. وضعیت آن را تغییر دهید.
4. جستجو و فیلتر اولویت را هم‌زمان امتحان کنید.
5. صفحه را بازخوانی و حفظ اطلاعات را بررسی کنید.
6. کار را انجام‌شده کنید و آمار را بررسی کنید.
7. کار را حذف کنید و دوباره صفحه را بازخوانی کنید.

حالت‌های ورودی خالی، فقط فاصله، لغو ویرایش، لغو حذف،
جستجوی بدون نتیجه و حذف آخرین کار نیز بررسی شوند.

در عرض کم، کنترل‌ها باید قابل مشاهده باشند.
با کلید Tab باید بتوان میان کنترل‌ها حرکت کرد.
هنگام استفاده، Console مرورگر را برای خطا بررسی کنید.
